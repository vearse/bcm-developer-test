endpoint.php is a WordPress must-use plugin, not a page you open in the browser. Copy it into wp-content/mu-plugins/ (same install as this bcm-test folder), then call POST /wp-json/bcm/v1/articles/{post_id}/status with JSON {"status":"draft"|"pending"|"publish"} while logged in and sending a valid X-WP-Nonce. Try a Contributor publishing a draft and an unauthenticated request; both should be rejected. Details are in ../answers.md.
